# وكيل فيديو أفق — MVP محلي

أداة CLI تحوّل وصف فيديو بالعربي إلى إعدادات JSON بواسطة Groq، ثم تستخدم قالب Remotion لتصدير فيديو MP4 محليًا. لا توجد واجهة ويب أو خدمة خادم، ولا تُنشر الأداة على Cloudflare أو ضمن موقع الوكالة.

## المتطلبات

- **Node.js 18+** وnpm؛ يُفضّل إصدار Node.js LTS مدعوم حاليًا (22 أو أحدث).
- مفتاح Groq صالح، واتصال بالإنترنت لاستدعاء Groq.
- في أول تصيير قد ينزّل Remotion متصفح Chrome Headless Shell تلقائيًا؛ يلزم اتصال بالإنترنت ومساحة كافية. على Linux قد تحتاج مكتبات النظام الخاصة بـ Chrome. راجع [متطلبات Remotion على Linux](https://www.remotion.dev/docs/miscellaneous/linux-dependencies) عند ظهور خطأ في تشغيل المتصفح.
- خط نظام يدعم العربية. القالب يستخدم `system-ui, Arial, sans-serif` ولا ينزّل خطوطًا خارجية.

## التثبيت والإعداد

من جذر مستودع `ofoq-agency`:

```sh
cd tools/video-agent
npm install
cp .env.example .env
```

افتح `.env` وضع المفتاح بدل القيمة التجريبية:

```dotenv
GROQ_API_KEY=your_key_here
```

لا تشارك المفتاح ولا ترفعه إلى Git. يقرأ السكربت المفتاح من `process.env` عبر `dotenv`؛ ويمكن تمريره كمتغير بيئة بدل ملف `.env`. الوصف يُرسل إلى Groq، أما التصيير وملف الفيديو فمحليان.

## التشغيل

```sh
npm start
```

مثال على الجلسة:

```text
اكتب وصف الفيديو: فيديو إعلاني لعطر ذهبي وأسود، 30 ثانية

جاري التحليل...
فهمت الطلب: { duration: 30, title: '...', subtitle: '...', ... }

جاري إنشاء الفيديو...

الفيديو جاهز: output/video-1234567890.mp4
```

ينشأ `output/` تلقائيًا عند التصيير، حتى في نسخة جديدة من المستودع. الملفات داخل `tools/video-agent/output/` مستثناة من Git. الأداة مستقلة بحزمها؛ لا يلزم تثبيت حزم الموقع لتشغيلها.

### أمثلة المدة

| الوصف | المدة |
| --- | --- |
| فيديو إعلاني لعطر ذهبي، 15 ثانية | 15 ثانية |
| فيديو 30 ثانية لمطعم | 30 ثانية |
| فيديو إعلاني | 15 ثانية (افتراضي) |
| فيديو لعطر، ٣٠ ثانية | 30 ثانية |
| فيديو مدته ثانيتان | 5 ثوانٍ (الحد الأدنى) |
| فيديو مدته 90 ثانية | 60 ثانية (الحد الأقصى) |

Groq يستخرج المدة من الوصف باستخدام النموذج `llama-3.3-70b-versatile` ووضع JSON. يطلب منه استخدام المدة المذكورة، أو **15 ثانية** عند عدم ذكرها. يتحقق الكود من النصوص والألوان، ويقرّب المدة لأقرب ثانية ويحصرها بين **5 و60**؛ المدة المفقودة أو غير الرقمية تصبح 15. تُعرض الإعدادات الناتجة في Terminal لتتمكن من مراجعة تفسير النموذج.

## الإعدادات والقالب

```json
{
  "duration": 30,
  "title": "عطر الفخامة",
  "subtitle": "أناقة ذهبية تترك أثرًا لا يُنسى",
  "backgroundColor": "#000000",
  "textColor": "#FFFFFF",
  "accentColor": "#D4AF37"
}
```

- فيديو مربع **1080×1080**، **30 إطارًا/ثانية**، MP4 بترميز H.264 و`yuv420p`.
- المدة ديناميكية عبر `calculateMetadata`: الافتراضي **450 إطارًا**، و30 ثانية تساوي 900 إطار.
- الخلفية والألوان والنصوص تأتي من props فقط؛ لا نص إعلاني ثابت داخل `AdVideo`.
- الحركات نسبية للمدة: ظهور الخلفية 0–7%، انزلاق العنوان 7–20%، ظهور النص الفرعي 20–40%، عرض ثابت 40–80%، اختفاء 80–100% حتى السواد في آخر إطار.
- يدعم العربية واتجاه RTL. هذا MVP نصي: لا يولّد صورًا أو تعليقًا صوتيًا أو موسيقى.

## التحقق والاختبارات

من داخل `tools/video-agent/`:

```sh
npm run build
npm test
```

`build` يشغّل TypeScript بوضع `noEmit` للتحقق من الأنواع؛ التشغيل عبر `tsx` ولا يتطلب ملفات JavaScript مبنية. الاختبارات في `tests/video-agent.test.ts` داخل هذه الأداة وتعمل بإعداد Vitest مستقل، دون قاعدة بيانات الموقع. تشمل الحزم، Groq مع mock، المدد والحدود، التحقق من JSON، إعدادات Remotion والحركات، وتنسيق إخراج MP4. لا تستدعي Groq الحقيقي ولا تشغّل تصييرًا أو متصفحًا حقيقيًا، ولا تحتاج مفتاح API.

ثُبّتت حزم Remotion على الإصدار نفسه لتجنب اختلاف الإصدارات، واختير Groq SDK 0.37 لدعم Node.js 18. ملف `package-lock.json` يحفظ التثبيت القابل للتكرار (`npm ci`).

## معالجة الأخطاء

- **المفتاح مفقود:** تأكد من تعديل `.env` داخل مجلد الأداة أو ضبط `GROQ_API_KEY`.
- **401 / 429 من Groq:** تحقق من المفتاح، وصلاحيات النموذج، وحدود الاستخدام ثم أعد المحاولة.
- **JSON أو ألوان غير صالحة:** تتوقف الأداة قبل التصيير مع رسالة خطأ؛ أعد المحاولة بوصف أوضح.
- **فشل المتصفح/التصيير:** تحقق من اتصال التنزيل الأول، ومكتبات Linux، ومساحة القرص وصلاحيات `output/`.

عند الفشل تنتهي العملية برمز خروج غير صفري ولا تطبع رسالة نجاح.
