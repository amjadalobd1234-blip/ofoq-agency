# صورة الشخص

تُحمّل صورة تجريبية من Unsplash إلى `man-1.png` عند غيابها أو فراغها، في خلية Colab 6 أو عند تشغيل `bash python/setup_models.sh`؛ لا يحدث تنزيل أثناء توليد الفيديو، ولا تُدرج الصورة في Git.

لاستبدالها، انسخ صورتك إلى `assets/avatars/man-1.png` قبل الإعداد أو بعده؛ لا يكتب التنزيل فوق ملف غير فارغ. أو عدّل `DEFAULT_AVATAR` في `.env` إلى مسار PNG/JPG محلي آخر. الأفضل صورة **512×512** لشخص واحد بوجه أمامي واضح وإضاءة جيدة، دون حجب العينين أو الفم.

الصورة التجريبية خاضعة لترخيص Unsplash **وليست CC0**؛ لا يفترض الترخيص موافقة الشخص على استخدام صورته في إعلان مولّد. قبل النشر، تأكد من حقوق الصورة وموافقة صاحب الوجه على تحريكها واستخدامها إعلانيًا.
