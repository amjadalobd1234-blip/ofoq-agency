# خطوط محلية

الافتراضي خط النظام. ثبّت خطًا يدعم العربية (مثل Noto Sans Arabic) على جهاز التصيير.
لثبات المظهر بين الأجهزة، ضع خط WOFF2 مرخّصًا هنا واضبط `FONT_FILE=assets/fonts/name.woff2`.
يُنسخ الخط إلى حزمة التصيير المحلية، دون Google Fonts أو أي عنوان خارجي.
احتفظ بترخيص الخط؛ ملفاته الخاصة مستثناة من Git.
